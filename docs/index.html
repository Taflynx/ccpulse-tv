What's on the screen

An album of screens on rotation, every 20 seconds by default. The usage and clock screens are re-rendered on your server and re-uploaded on a schedule. The animations and the boot screen are uploaded once.

01 · USAGE

Your limits, against the clock

% used for each limit window (5-hour, weekly…), with a marker for how far into the period you are. Green when you're under pace, amber when you're ahead of it, red near the cap. Data comes from ccpulse.

02 · CRITTER

A tiny Claude with moods

Idle blinking, a walk across the screen, a happy jump with sparkles, thinking with a spinning spark, and sleeping with Zs. Plus an animated boot screen.

03 · TIME

Big clock with an orange colon, your city's conditions with a pixel icon, feels-like, today's high/low and tomorrow. Open-Meteo, no API key.

How it works

The SmallTV-PRO already has a photo-album mode and an HTTP upload endpoint. ccpulse-tv simply feeds that album.

ccpulsereads your official Claude limits: % used, period start/end
→
RenderersPillow draws 240×240 screens and writes GIFs
→
smalltv.pycron: usage every 10 min, clock every minute
→
POST /doUploadsame filename overwrites; the album picks it up
→
SmallTV-PROPicture app, autoplay, stock firmware

Quick start

# 1. needs Python 3 + Pillow, and ccpulse for the usage screen
git clone https://github.com/Taflynx/ccpulse-tv && cd ccpulse-tv
cp config.example.env config.env   # device IP + your city

# 2. upload animations + boot screen, configure the album
python3 smalltv.py setup

# 3. keep usage + clock fresh
python3 smalltv.py cron | crontab -   # or append it to yours

The GIF gotcha

GIFs that look perfect on your PC can come out garbled on the device. Most encoders (Pillow, ezgif, ffmpeg) store only the changed rectangle of each frame. The SmallTV-PRO decoder expects full 240×240 frames with one global palette, the way its factory GIFs are built. ccpulse-tv ships a tiny LZW encoder that writes exactly that.

Switching apps over HTTP doesn't work. /set?theme= only sets the start-up app. That's why the clock and weather are drawn into the album, so everything shares one rotation.
